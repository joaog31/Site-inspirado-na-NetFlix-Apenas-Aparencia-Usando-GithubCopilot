# Site inspirado na Netflix (Apenas Aparencia)

Este repositorio contem um projeto de estudo desenvolvido durante a **Imersao Alura de Front-end**.

## Sobre o projeto

A proposta deste site e reproduzir a aparencia da interface da Netflix para fins educacionais, praticando conceitos de HTML, CSS e JavaScript.

## Uso de IA no desenvolvimento

Este projeto esta sendo desenvolvido com apoio de **IA GitHub Copilot** para gerar e sugerir partes do codigo do site.

## Objetivo

- Praticar desenvolvimento Front-end
- Evoluir estrutura de pagina e estilos visuais
- Explorar apoio de IA no processo de programacao
